# Safello

> Safello is a Swedish cryptocurrency brokerage (founded 2013, registered with Finansinspektionen, listed on Nasdaq First North Growth Market) that lets users buy, sell, and store digital assets. Its Institutional API offers "Cryptocurrency as a Service" (CaaS) to third-party organisations — market data, customer onboarding (BankID + KYC), buy/sell/trade orders, wallets, and compliance verification.

## APIs

- [Safello Institutional API (v2.2.30)](https://safello.github.io/safello-api/api): Cryptocurrency-as-a-Service REST API. Base URL https://api.safello.com. OAuth2 (client credentials, authorization code, custom BankID grant) + Basic auth. 34 operations across Market, Account, Orders, Wallet, and Compliance.
- [Safello App API (v1)](https://safello.github.io/safello-api/docs/intro): Legacy consumer app API at https://app.safello.com (AccessToken + App-Id headers).
